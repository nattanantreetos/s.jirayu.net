# SEEN Split Tunnel

`seen-split-tunnel.ovpn` เป็นโปรไฟล์ส่วนตัว มีใบรับรองและกุญแจจากไฟล์เดิม ห้ามแชร์หรืออัปโหลดขึ้นเว็บไซต์/Git
สร้างจาก `D:\Downloads\seen.ovpn` โดยไม่แก้ต้นฉบับ

โปรไฟล์นี้ไม่รับ routes/DNS จากเซิร์ฟเวอร์ แล้วเพิ่มเฉพาะ 10.3.0.0/16 ผ่าน VPN
เครือข่ายนี้อ้างอิงตารางเส้นทางที่ตรวจพบในเครื่อง ถ้าเซิร์ฟเวอร์ต้องใช้เครือข่ายอื่น ต้องเพิ่มให้ตรงข้อมูลจริง
ยังใช้ OpenVPN อยู่ แต่ไม่ใช่ full tunnel และไม่ใช่การแยกตามโปรแกรม

วิธีทดสอบ:
1. Import `seen-split-tunnel.ovpn` เป็นโปรไฟล์ใหม่ใน OpenVPN ที่ใช้อยู่ ไม่แทนที่โปรไฟล์เดิม
2. Disconnect โปรไฟล์เดิม แล้ว Connect โปรไฟล์ใหม่ ห้ามเชื่อมทั้งสองพร้อมกัน
3. ตรวจ `route print -4` ต้องไม่มี 0.0.0.0/1 และ 128.0.0.0/1 ผ่าน 10.8.0.1
4. ต้องมี 10.3.0.0/16 ผ่าน VPN แต่ default route ใช้เราท์เตอร์ปกติ
5. ตรวจ `route print -6` ว่าไม่มี VPN redirect หรือ block IPv6 ที่ค้างจากโปรไฟล์เดิม
6. เปิดเว็บที่เผยแพร่จากโทรศัพท์และลองเกมจริง เพื่อยืนยันการทำงานทั้งสองส่วน

หาก import ไม่ผ่าน ให้ส่งเฉพาะข้อความ error ห้ามส่งกุญแจ/ใบรับรอง
หากเว็บเข้าไม่ได้ ให้ Disconnect โปรไฟล์นี้แล้วกลับไป Connect โปรไฟล์เดิม
การเชื่อมโปรไฟล์เดิมอีกครั้งอาจกลับไปเป็น full tunnel เหมือนเดิม

ตอนสร้างไฟล์ยังไม่ได้เชื่อมต่อโปรไฟล์ใหม่หรือเปลี่ยน routing ของเครื่อง
