# Drive (ย้ายที่เก็บแล้ว)

ระบบปัจจุบันเก็บไฟล์ใน D:\all\all\ai-seen1236\web\Dirve
ไฟล์อัปโหลดเดิมถูกย้ายไปที่นั่นแล้ว โฟลเดอร์นี้ไม่ใช่พื้นที่จัดเก็บที่ระบบใช้อีกต่อไป

พื้นที่อัปโหลดของเว็บ จำกัดเนื้อหาไฟล์รวม 1,000,000,000 ไบต์ (1 GB)
ไฟล์จริงเก็บเป็น UUID.bin และชื่อเดิม/วันอัปโหลดเก็บใน UUID.json
ไฟล์ .part คือข้อมูลอัปโหลดไม่ครบและนับรวมพื้นที่ด้วย

ไม่มี API ดาวน์โหลด เปิดไฟล์ หรือลบไฟล์ผ่านเว็บ โดยเซิร์ฟเวอร์ปิดการเข้าถึง /Dirve/
ข้อมูลถูกเก็บในเครื่องที่รัน web/server.js ไม่ใช่ Google Drive
ผู้เข้าถึงเว็บไซต์สามารถอัปโหลดและเห็นรายชื่อไฟล์ได้ พื้นที่นี้เป็นพื้นที่ร่วม ไม่ใช่บัญชีส่วนตัว
